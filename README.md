# webgpu-linetowerwars

A web-based, multiplayer reimagining of the Warcraft III custom map
*Line Tower Wars*, rendered in isometric 3D with three.js and WebGPU.

It's the sister project to
[webgpu-gemtd](https://github.com/kellymilligan/webgpu-gemtd).

**Status:** pre-design. Start with:
- [`docs/LTW-BRIEF.md`](docs/LTW-BRIEF.md) for the game and open questions;
- [`docs/LEARNINGS.md`](docs/LEARNINGS.md) for lessons from Gem TD;
- [`CLAUDE.md`](CLAUDE.md) for working conventions.

`reference/gemtd/` holds curated source files from Gem TD to adapt. It isn't
built or imported.
